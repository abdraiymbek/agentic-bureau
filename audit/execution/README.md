## Measurements

Evidence files preserve scope and raw samples:

- [Graph before/after](../pre-release/evidence/graph-execution-performance.json): same synthetic selected-revision chain. Before: 2,000-node impact **1,432–1,662 ms**, silently depth-truncated; root edit **1,443 ms**, only one stale downstream object. After: five impact samples **7.19–13.76 ms**, complete affected set; root edit **346 ms**, all **1,999** downstream objects stale. Display-path compression reduced the intermediate full-path JSON from **78,321,884** to **2,843,130 bytes**.
- [Final 30-sample graph probe](evidence/graph-impact-30.json), reproduced with `pnpm exec tsx audit/execution/measure-graph.ts`: **p50 12.881 ms; p95 23.856 ms** on Apple M5 / 16 GiB / Node 24.19.0. No excluded warmup; nearest-rank percentiles. A separate single root edit took **427 ms**. Command timings exclude JSON serialization, bridge and renderer; this is not the whole-desktop reference performance test.
- [Mesh workload probes](../pre-release/evidence/mesh-execution-performance.json): adversarial 2,000-triangle overlapping pair checks formerly blocked **929.58 ms**; now reject after the supported overlap budget in **41.53 ms**. A 20,000-triangle quadratic request rejects before traversal in **0.037–0.143 ms**. This is bounded rejection, not faster completion of the same full computation. A supported 100,000-triangle analysis still took **401.98 ms**; parsing took **2.88 ms**. These are individual samples, not p95 measurements.

There is **no claim of a 100 ms maximum core stall, 32 KiB general tool response, desktop RSS budget, viewport performance, startup budget, or whole-desktop p95**. Synthetic process RSS includes fixture/result allocation. The old `audit/pre-release/measure.ts` intersection loop intentionally requests sizes now rejected by the workload policy; use the new graph-only reproducer for repeatable final graph measurements.

## Supported scope and explicit limits

- Initial desktop target: **macOS arm64**. Linux is currently an engine CI gate; Windows packaging/smoke is experimental and non-blocking. No new cross-platform release claim.
- CAD remains OpenSCAD plus STL triangle geometry. These changes do not introduce exact B-rep/STEP, mates, FEA, collision certification or manufacturability certification.
- STL analysis: **6,000,000 bytes**, **100,000 finite complete triangles**. The byte cap leaves room for base64 and ordinary overhead within the unchanged **8 MiB bridge frame**; it is not a bound on every possible tool envelope.
- Verification: **512** requested point/section-feature assertions and **10,000,000** estimated triangle visits per operation. Public inspection already permits at most **64 probes / 12 extra planes**; the internal guard additionally budgets up to five automatic planes.
- Self-intersections: **8,000,000 candidate pairs**, **100,000 overlapping bounding-box pairs**. Work-limit errors use `VALIDATION` with `reason: CAD_WORK_LIMIT` and `status: not_evaluated`. Omitting a rejected check does not establish its result.
- Terminal history: **256 × 1,024 JavaScript characters** held in memory for the current session. This is bounded renderer restoration, not durable conversation/task memory or recovery after core-process death.

## Remaining work: exact handoff

1. **Finish release acceptance.** Run the new Linux engine CI gate and root's rebuilt native/Luna acceptance matrix. Keep exact engine/model/configuration/results. Deterministic evaluator regressions cannot substitute for model runs; historical `lastCheckPassed` now has stricter final-evidence semantics and old/new pass rates need that qualification.
2. **Graph response/persistence budgets.** Implement paged/on-demand impact explanations and compact stale predecessor evidence, retaining complete affected-node coverage. The current 2.84 MB impact response exceeds the model-context target and full stored paths have quadratic size on long chains. Re-run 2,000-node correctness plus 30-sample serialized transport measurements; do not silently truncate affected objects. Optimize/worker-isolate root-edit propagation only with correctness retained.
3. **Worker execution remains unfinished.** Move supported heavy mesh analysis to cancellable workers with progress and checked result identity. Test maximum supported geometry under concurrent terminal/renderer interaction. Work limits bound cost; the measured 402 ms analysis does not meet the 100 ms stall goal.
4. **Terminal snapshot/live-stream ordering.** Project/session envelopes match across utility, main, preload, App and TerminalPane; the panel is keyed by project and delayed store refreshes are generation-guarded. However snapshot history and live bytes have no sequence cursor. Output concurrent with restoration can be duplicated or reordered. Add a session output sequence and atomic snapshot cursor, buffer/replay only newer frames, and test continuous output during reload, project switch and session restart. Do not fix this by subscribing after history retrieval, which can lose bytes.
5. **Qualify the implemented quit handshake.** Integration added an idempotent `before-quit` barrier in `apps/desktop/src/main/main.ts`: await utility exit, with a five-second kill fallback. Core awaits concurrent session shutdown before closing databases. The final package includes this change. Test quitting during PTY startup, a running agent and OpenSCAD work, including escalation/forced-exit behavior; the complete native fault matrix has not run.
6. **Independent correctness oracle and broader agents.** The evaluator independently renders the final source, but shares the product's mesh/checker implementation. Preserve analytic fixtures and add independent reference comparisons plus repeated multi-step/provider evals before stronger capability claims. Model runs must verify final artifact identity, not textual tool success.

No new worker framework, project-format migration, default transport limit increase, task-memory subsystem or visual redesign was added by this track. Preserve the current deterministic limits and explicit unknown states while completing the remaining master-plan gates.
