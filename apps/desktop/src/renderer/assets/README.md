# Welcome screen assets

- `omenflow-aircraft.png`: artwork supplied by the user for the Omen Flow welcome screen. The original pixels are preserved; the launcher frames its black margins in CSS.
- `Michroma-Regular.ttf`: Michroma by Vernon Adams, from https://github.com/google/fonts/tree/main/ofl/michroma. Bundled under the SIL Open Font License in `OFL-Michroma.txt`.

Both assets are bundled by Vite and available offline.
